ZamexCards Pokémon TCG Kaartzoeker
==================================

Deze versie bevat alleen de kaartzoeker en geen scanner.

GitHub Pages installeren:
1. Pak het ZIP-bestand uit.
2. Upload index.html naar de hoofdmap van een nieuwe GitHub-repository.
3. Open in GitHub: Settings > Pages.
4. Kies Deploy from a branch, branch main en map /(root).
5. Sla de instelling op.

Zoeken kan op:
- complete TCG-setlijst (gewone sets nieuwste bovenaan, promo-sets onderaan)
- set of setcode, inclusief promo- en specialsets
- kaartnaam
- kaartnummer
- uitvoering/variant
- Engels, Japans, Chinees en Koreaans
- conditie (Near Mint is standaard)
- graded of niet graded, gradingbedrijf en grade

De setcatalogus, kaartgegevens en prijzen worden via openbare gratis databronnen
geladen. TCGdex blijft de standaard prijsbron; TCGCSV wordt automatisch als
variantgerichte back-up gebruikt. Daarom is een internetverbinding nodig.
